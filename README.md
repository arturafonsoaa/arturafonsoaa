## 🚀 What I've Been Building

- **Healthcare platform:** Laravel and Filament modules for clinics, fast check-in, asynchronous care with specialty-specific anamnesis forms, chat and order transfers, plus pharmacy dispensing, hospitalization records, reports and daily billing jobs.
- **[IdealPro](https://www.idealpro.ai/) AI agents:** natural-language understanding of financial questions (due dates, settlements, balances, payment promises) and of a WhatsApp collections channel. On the runtime side: per-pod in-flight limits, token accounting and structured run logs.
- **[Unitrends University](https://www.unitrends.online/) enrollment ("Matrícula Fácil"):** a multi-step Livewire wizard that students can resume, with PT/EN/ES terms, card checkout through a payment gateway and academic ERP provisioning.
- **EMA school management system:** Laravel 13 and Livewire 4 with a strict modular architecture, PRDs, ADRs and a ubiquitous-language glossary.
- **Commercial intelligence at [Ideal Trends](https://www.idealtrends.com.br/):** a Next.js and Supabase platform with edge functions for lead segmentation, plus Python tooling to build ground-truth datasets.
